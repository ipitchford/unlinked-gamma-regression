# Assurance boundaries

Availability is established only when the public archives are read back. Producer replay passed in normal and optimized Python. Four semantic negative controls reject altered signs, shapes, the variance factor and the cumulant factorial. The checks use rational arithmetic and the standard library; this is implementation evidence for bounded instances, not machine-checked universal mathematics.

Independent external rerun and reimplementation, unaffiliated specialist review, editorial peer review, proof-assistant verification and historical priority are **not established**. Supplied review assertions are not authenticated evidence of external independence. Five producer-coordinated model roles are internal editorial review only. Environment reproducibility is partial: the Python checks are dependency-free, but no bit-identical TeX/container environment is guaranteed.
